wiwi_memory_usage

Trait MemoryUsageStatic 

Source 
pub trait MemoryUsageStatic: MemoryUsageConst {
    const MEMORY_USAGE: usize;
}
Expand description

Types that always have the same memory usage, regardless of value (notably different than Sized)
